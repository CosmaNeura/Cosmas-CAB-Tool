Risk: Tier 2 — billing evidence presentation and source boundary.

Outcome: an authorized current CAB encounter opens a focused editable header.
The reviewed-import shortcut opens a separate CAB tab, preserving the current
case and SMS draft. Only the explicit server header capability exposes it.

the generation hold for operational Athena, and keeps historical header editing
available after model-policy expiry. Date and source-reported note status travel
with the pinned encounter and copied reference, without editing its clinical text.
