# MCD synthetic staff training

Twelve newly authored fictional visits, including fertility/preconception cases
10–12. `encounters.json` preserves the original September 30, 2026 VisitBundle
input bytes. `metadata.json` records the input and original-manifest digests,
source attribution and limitations. The loader pins both packaged JSON files.

Selected history came from the single Synthea April 2020 CSV sample. Current
symptoms, examinations, plans, time and narrative context were authored for
these scenarios. The three fertility narratives are authored additions over
selected synthetic history. Fictional completion/signature wording is not an
actual clinician signature or review. These are source inputs for staff
practice, not clinician-validated examples or approved model-training data.

No source patient mappings, original tables, local source paths, model results,
expected billing codes or review scenarios are included. Original labels and
dates in the notes are fictional; this fixed pack is not a generic import path.
Code suggestions still require the full billing pipeline and human review.

Attribution: [Synthea](https://synthetichealth.github.io/synthea/). Its site
describes generated data as free from cost/privacy/security restrictions.
Synthea source code is Apache-2.0; the original source review found no separate
sample-data license. No blanket Apache-2.0 data or terminology license is claimed.
